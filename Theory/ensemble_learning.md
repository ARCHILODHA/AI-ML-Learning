# Ensemble Learning

## Definition

Ensemble Learning combines multiple machine learning models to produce a stronger and more reliable model.

The basic idea is that several models working together can perform better than a single model.

## Types

### Bagging

Bagging trains multiple models independently on different samples of the dataset.

Example:

- Random Forest

### Boosting

Boosting trains models sequentially, where each new model focuses on correcting errors made by previous models.

Examples:

- AdaBoost
- Gradient Boosting
- XGBoost

### Stacking

Stacking combines predictions from multiple models and uses another model to make the final prediction.

## Advantages

- Improved accuracy
- Better generalization
- Reduced variance
- More robust predictions

## Disadvantages

- More computationally expensive
- More difficult to interpret
- Requires more resources

## Applications

- Classification
- Regression
- Fraud detection
- Recommendation systems
