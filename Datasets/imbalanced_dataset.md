# Imbalanced Dataset

## Definition

An imbalanced dataset has unequal class distributions.

Example:

Spam = 5%

Not Spam = 95%

## Problems

- High accuracy but poor predictions
- Bias toward majority class

## Solutions

- Oversampling
- Undersampling
- SMOTE
- Class Weights

## Evaluation Metrics

- Precision
- Recall
- F1 Score
- ROC-AUC
