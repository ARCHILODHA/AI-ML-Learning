# Categorical Encoding

## Why Encoding?

Machine learning models require numerical inputs.

## Techniques

### Label Encoding

Assigns an integer to each category.

Example:

Red → 0

Blue → 1

Green → 2

### One-Hot Encoding

Creates binary columns.

Example:

Color_Red

Color_Blue

Color_Green

## Best Practice

- One-Hot Encoding for nominal data.
- Label Encoding for ordinal data.
