# K-Means Clustering

## Definition

K-Means is an unsupervised machine learning algorithm used to divide data into K different clusters.

## Working

1. Select the number of clusters K.
2. Randomly initialize K centroids.
3. Assign each data point to the nearest centroid.
4. Calculate new centroids.
5. Repeat the assignment and centroid calculation.
6. Stop when the centroids become stable.

## Objective

K-Means attempts to minimize the within-cluster sum of squared distances.

## Advantages

- Simple and easy to implement
- Fast for large datasets
- Easy to interpret

## Disadvantages

- K must be selected beforehand
- Sensitive to outliers
- Sensitive to initial centroid selection
- Works best with spherical clusters

## Applications

- Customer segmentation
- Image compression
- Market segmentation
- Pattern recognition
