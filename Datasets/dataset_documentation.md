# Dataset Documentation

## Purpose

Documentation helps users understand the dataset before training models.

## Should Include

- Dataset source
- Number of records
- Features
- Target variable
- Missing values
- License
- Collection date
- Version

## Benefits

- Easier collaboration
- Better reproducibility
- Improved transparency

## Example

Dataset Name: Customer Churn

Records: 10,000

Features: 18

Target: Churn (Yes/No)

License: CC BY 4.0
