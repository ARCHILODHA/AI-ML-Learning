# Naive Bayes

## Definition

Naive Bayes is a supervised machine learning classification algorithm based on Bayes' Theorem. It assumes that all features are independent of each other given the target class.

## Bayes' Theorem

P(A|B) = [P(B|A) × P(A)] / P(B)

Where:

- P(A|B) = Posterior probability
- P(B|A) = Likelihood
- P(A) = Prior probability
- P(B) = Evidence

## Types

1. Gaussian Naive Bayes
2. Multinomial Naive Bayes
3. Bernoulli Naive Bayes

## Advantages

- Simple and fast
- Works well with high-dimensional data
- Requires relatively little training data
- Useful for text classification

## Applications

- Spam detection
- Sentiment analysis
- Document classification
- Medical diagnosis

## Example

Naive Bayes can classify an email as spam or not spam based on the words present in the email.
