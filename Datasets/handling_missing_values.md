# Handling Missing Values

## Missing Data

Missing values occur when some observations are unavailable.

## Methods

### Remove Rows

Suitable when only a few records are missing.

### Mean Imputation

Replace missing values with the column mean.

### Median Imputation

Useful for skewed distributions.

### Mode Imputation

Best for categorical features.

### Forward Fill

Uses previous observation.

### Backward Fill

Uses next observation.

## Best Practices

- Analyze why data is missing.
- Avoid excessive deletion.
- Validate after imputation.
